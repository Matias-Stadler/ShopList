# Kata Lista de Compras (ShopList)
In this project, the objective is to design with [Laravel](https://laravel.com) an application that acts as a shopping list via endpoint.

## Languages ​​and tools  
![](https://skillicons.dev/icons?i=php,laravel,git,github,vscode,)

## Installation prerequisites
Install [Node.js](https://nodejs.org/en/download/source-code)

Install [Composer](https://getcomposer.org/download/)

## Installation Guide 
Before starting to install the project, you will need to create a database (we have used mysql via xampp) and name it: `shoplist` 

Open a terminal in the folder where you want the repository to be cloned and enter this command:

`https://github.com/Matias-Stadler/ShopList.git`
